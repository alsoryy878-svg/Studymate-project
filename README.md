# Studymate-project

## 📌 Description
StudyMate is a simple MVP application designed to help students manage their study tasks.

## 🎯 Features
- Add tasks
- View tasks
- Simple and easy interface

## 💡 MVP Concept
This project demonstrates a basic implementation of the system idea using a simple web application.

## 👨‍💻 Technologies Used
- HTML
- JavaScript

## 🚀 How to Run
Open the index.html file in your browser.

## 📎 Project Note
This is a basic MVP (Minimum Viable Product) developed for academic purposes.
